## 📝 CONTENT TEMPLATES

### YouTube Video Structure Template

```
HOOK (0-5 sec):
- Pattern interrupt
- Promise the value
- Example: "I made $10,000 last month using these 5 apps..."

INTRO (5-30 sec):
- Who you are (for new viewers)
- What they'll learn
- Why they should watch

MAIN CONTENT (varies):
Point 1: [Tip/Tool]
- Explanation
- How to use
- Personal example

Point 2: [Tip/Tool]
- etc.

OUTRO (last 30 sec):
- Recap key points
- Call to action (subscribe, comment, check description)
- Tease next video
```

### TikTok Caption Formula

```
[HOOK QUESTION OR STATEMENT]

[Value delivery in 2-3 lines]

[Call to action]

#hashtag1 #hashtag2 #hashtag3 #trending
```

**Example:**
```
Ever wonder how creators make $10K/month? 👀

Here's exactly how I do it:
AdSense, brand deals, and this ONE platform...
(Full breakdown in comments 👇)

Drop a 💰 if you want more money content!

#contentcreator #makemoneyonline #sidehustle #entrepreneurship
```

### Instagram Carousel Template

**Slide 1: Hook**
- Big promise or question
- Eye-catching design
- Clear topic

**Slides 2-8: Value**
- One tip per slide
- Visual + short text
- Actionable steps

**Slide 9: Recap**
- Summarize key points
- Reinforce value

**Slide 10: CTA**
- Follow for more
- Share with friends
- Comment your thoughts
