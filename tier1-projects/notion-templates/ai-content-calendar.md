## 🤖 AI PROMPT LIBRARY

### PROMPT #1: Twitter Thread Generator
```
I need a Twitter thread about [TOPIC]. My audience is [TARGET AUDIENCE].

Create an 8-tweet thread that:
- Starts with a compelling hook (first tweet)
- Provides actionable insights
- Uses simple language and short sentences
- Ends with a CTA to follow me for more

Topic: [Your topic here]
My unique angle: [What makes your perspective different]

Format each tweet as:
Tweet 1/8: [content]
Tweet 2/8: [content]
etc.
```

**Example Output Topic**: "How to go from $0 to $10k MRR as a solopreneur"

---

### PROMPT #2: LinkedIn Carousel Post
```
Create a 10-slide LinkedIn carousel about [TOPIC].

Audience: [Your target audience]
Goal: [Educate/Inspire/Sell]

Each slide should have:
- A clear headline (max 6 words)
- 2-3 bullet points of content
- Simple, actionable takeaways

Format:
Slide 1: [Hook headline]
Content: [What problem you're solving]

Slide 2-9: [Main content]
...

Slide 10: [CTA]

Topic: [Your topic]
```

**Example Output Topic**: "5 Productivity Mistakes Costing You $10k/Year"

---

### PROMPT #3: YouTube Video Script (Short Form)
```
Write a 60-second YouTube Shorts script about [TOPIC].

Structure:
0-3 sec: Hook (make them stop scrolling)
3-15 sec: Setup (the problem)
15-45 sec: Solution (3 quick tips)
45-60 sec: CTA (subscribe for more)

Make it:
- Conversational (like I'm talking to a friend)
- Fast-paced
- Include exact words to say on camera

Topic: [Your topic]
```

---

### PROMPT #4: Newsletter Email Template
```
Write a weekly newsletter email with this structure:

Subject Line: [Catchy, makes them want to open]

Email Body:
1. Personal intro (50 words) - What I've been up to this week
2. Main Insight (200 words) - One valuable lesson/tip
3. Quick Wins (3 bullet points) - Actionable takeaways
4. Resource of the Week - Tool/article/book recommendation
5. P.S. - Teaser for next week

Tone: Friendly, helpful, like writing to a friend
Topic focus this week: [Your topic]
```

---

### PROMPT #5: Viral Tweet Formula
```
Create 5 variations of a tweet about [TOPIC] using this formula:

[Unexpected Statement] + [Why It Matters] + [What To Do Instead]

Requirements:
- Max 280 characters
- No hashtags
- Conversational tone
- Make people want to reply/retweet

Topic: [Your controversial/interesting take]
```

### PROMPT #6: LinkedIn Thought Leadership Post
```
Write a LinkedIn post (300 words) about [TOPIC] that positions me as a thought leader.

Structure:
- Start with a personal story/observation
- Connect it to a bigger industry trend
- Provide 3-5 insights
- End with a question to drive engagement

Tone: Professional but approachable, authoritative but humble

Topic: [Your expertise area]
My unique experience: [What qualifies you to talk about this]
```
